# Vision Trading Academy — website

A ready-to-deploy, mobile-responsive, single-page static website for Vision Trading Academy.

## Preview
Open `index.html` in a browser. Google Fonts requires internet access; fallback fonts are provided.

## GitHub Pages deployment
1. Back up the existing RA Trading Academy repository before changing it.
2. Upload `index.html` and the `assets` folder to the root of your GitHub Pages repository, replacing the old homepage and matching asset files.
3. In GitHub repository Settings → Pages, ensure the deployment branch is `main` and folder `/ (root)`.
4. Check the published site and mobile view. If desired, retain old URLs with redirects to the new homepage.

## Review before publishing
- Verify the address, phone number, email and Instagram handle.
- Replace the generic curriculum summaries with your exact 15-day syllabus if needed.
- Confirm the Google Business Profile and website use the same new name.
- Update the website URL in your Google Business Profile, then submit the URL to Google Search Console for indexing.
- The logo image is embedded as a PNG; replace with a licensed vector version later if you need print-quality artwork.

## Notes
The existing website is NOT automatically changed by this package. Course fees and batch dates are intentionally not invented. The website does not collect form data; enquiries go directly to WhatsApp.
