VISION TRADING ACADEMY - LUXURY WEBSITE REPLACEMENT

Ready for GitHub Pages, no build tools required.

1. Extract this ZIP.
2. Open https://github.com/visiontradingacademy/visiontradingacademy
3. Upload index.html to the repository root (replace the existing index.html).
4. Upload the three files from assets/ into your repository's existing assets/ folder (replace style.css and script.js; add favicon.svg).
5. Commit changes on main. Wait for the Pages deployment in Actions.
6. Hard refresh https://visiontradingacademy.github.io/visiontradingacademy/

No additional premium-effects files are needed; the new index.html does not reference them.
The website is a single-page responsive design. Bull/bear clip-art overlays have been removed.
Animated candlesticks are illustrative only and do not use live market prices.
Review count and star ratings are intentionally omitted until verified.
The branding is recreated in text and vector shapes to avoid reliance on missing image files.
Confirm the contact email and course availability before publishing.
